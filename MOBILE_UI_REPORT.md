# Этап 6: мобильная адаптация интерфейса

## Реализовано

- Короткие страницы обучения вместо прокручиваемых инструкций. На телефоне памятка открывается перед практикой; «К практике» сворачивает её до задания, «?» открывает снова. На время чтения спарринг и его таймеры остановлены, Gameplay API учитывает это состояние.
- Экскурсия по лобби и комнатам: страницы текста, постоянно доступные маршрут и пропуск. В горизонтальном положении настройки и меню перенесены в верхнюю панель, характеристики размещены в один ряд.
- Карьерная доска: отдельные представления списка четырёх соперников, досье и правил. Четыре страницы карьерного обучения. Доступны все двенадцать досье, замки, счёт сохранённого матча и его продолжение.
- Выбор техники: вкладки стилей, трёх слотов свободного набора и правил. Кнопка «Готово» остаётся доступной.
- Обучение жиму: четыре страницы. Панель настоящего QTE и результат подхода адаптированы к телефону.
- Компактные настройки, подтверждение новой игры, результаты боёв. В паузе управление, комбинации и правила разделены вкладками.
- Сохранены настольная версия, прогресс, награды и боевая механика.

## Как проверить

1. Выполнить `npm run dev -- --host 0.0.0.0 --port 5185`.
2. На телефоне в той же сети открыть адрес из строки `Network`, которую выведет Vite. На компьютере — `http://127.0.0.1:5185/`.
3. Проверить новую игру, памятки и «К практике», затем кнопку «?». Прочитать пояснения до последней страницы.
4. Проверить экскурсию, окно техники и три слота свободного стиля, карьерные карточки/досье/правила, жим и его результат, настройки и паузу боя.
5. Повторить в вертикальном и горизонтальном положении телефона.

## Ограничения и статус

Проверки выполнялись в Chrome с эмуляцией размеров и настоящих сенсорных событий. Физические Android/iPhone и Safari в этой доработке не проверены. Системный список выбора приёма использует стандартный интерфейс браузера; игровые окна и пояснения не требуют прокрутки на проверенных размерах.

Пользователь разрешил коммит доработки в `main`, отправку в удалённый репозиторий и публикацию через существующий workflow GitHub Pages. Публикация проверяется отдельно по результату GitHub Actions и содержимому общедоступной сборки.
