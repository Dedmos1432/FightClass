# Класс удара

Одиночный 2D-файтинг на TypeScript, Phaser 3 и Vite. Сейчас реализован **только этап 1 — главное меню**. Разработка следующего этапа начинается после отдельного одобрения пользователя. Сетевых боёв и серверной части нет.

## Запуск

Требуется Node.js 22.12+ и npm. Из папки `C:\Game develop\FightClass3`:

```powershell
npm install
npm run dev
```

Открыть <http://127.0.0.1:5173>. Не открывать `index.html` двойным щелчком: игре нужен локальный сервер.

## Готово в этапе 1

- Пиксельное оформление меню с фоном арены из предоставленной папки `resourse` и движущимися частицами.
- «Начать игру»: создаёт локальное сохранение первого класса и открывает отдельную сцену входа в лобби.
- «Продолжить»: недоступно без корректного сохранения, возвращает в сохранённую сессию после перезагрузки.
- Повторная новая игра требует подтверждения замены сохранения. Отмена сохраняет прежнюю сессию.
- «Настройки»: громкость синтезированных звуков интерфейса, включение звука, анимация фона. Изменения сохраняются автоматически.
- Кнопки звука и полного экрана; полный экран также переключается клавишей F.
- Управление меню мышью и клавиатурой: Tab / Shift+Tab — выбор, Enter / Space — нажатие. Escape закрывает диалог; в сцене входа в лобби возвращает в меню.
- Диалоги удерживают фокус и возвращают его к исходной кнопке после закрытия. Интерфейс адаптируется к размеру окна.
- Проверка схемы сохранения, защита от повреждённого JSON и недоступного localStorage. При отказе хранилища игра работает в памяти и сообщает об этом.

Сцена входа в лобби — минимальная цель перехода для проверки меню. В ней намеренно нет перемещения, дверей, доски, тренировок, боёв или выбора стиля. Это задачи следующих согласованных этапов.

## Структура

```text
src/
  config/game.ts           — название, версия, ключи хранилища, сцены
  core/GameServices.ts     — единая точка подключения сервисов
  scenes/BootScene.ts      — загрузка ресурса, обработка ошибки
  scenes/MainMenuScene.ts  — главное меню и запуск сессии
  scenes/LobbyEntryScene.ts— минимальный вход в лобби и возврат
  scenes/ArenaBackdrop.ts  — фон Phaser, масштабирование, частицы
  services/               — сохранение, настройки, хранилище, звук
  ui/                     — DOM-интерфейс, модальные окна, иконки
  styles.css              — оформление и адаптация
  main.ts                 — создание Phaser.Game и жизненный цикл
tests/                    — проверки сохранений и браузерные сценарии
resourse/                 — исходная графика пользователя (не изменена)
```

В сборку этапа 1 попадает только используемый фон. Остальные 506 изображений не копируются в сборку. Сторонние шрифты, изображения и аудио из сети во время игры не загружаются.

Ключи localStorage: `fightclass3.session.v1`, `fightclass3.settings.v1`. На этапе 1 сессия содержит идентификатор, даты создания/обновления, первый класс и расположение `lobby`. Полная схема характеристик появится вместе с соответствующей механикой. Облачное сохранение и SDK Яндекс Игр относятся к этапу 6.

## Проверки

```powershell
npm run typecheck
npm run build
npm test
```

Браузерные тесты используют установленный Google Chrome (`channel: chrome`). Если его нет, установить Chrome или выполнить `npx playwright install chrome`. `npm run test:storage` запускает только проверки сервисов, `npm run test:browser` — интерфейс. Playwright сам запускает локальный Vite-сервер; занятый порт 5173 должен обслуживать именно этот проект.

Для проверки **собранной** версии:

```powershell
npm run build
npm run preview
```

Открыть <http://127.0.0.1:4173>. Порты 5173 и 4173 имеют разные локальные сохранения — это поведение браузера.

Два основных браузерных сценария можно прогнать на собранной версии (PowerShell):

```powershell
$env:PLAYWRIGHT_PREVIEW = '1'
npm run test:browser -- --grep 'меню запускается|новая игра, возврат' --output=test-results/preview
Remove-Item Env:PLAYWRIGHT_PREVIEW
```

## Ручная приёмка этапа 1

1. На первом открытии «Продолжить» недоступно. Проверить меню мышью и Tab / Enter.
2. Открыть настройки, изменить громкость, выключить звук и фон. Закрыть через «Готово» или Escape. После перезагрузки выбор должен сохраниться.
3. Нажать «Начать игру». Должна открыться сцена «Добро пожаловать в клуб» с первым классом и отметкой сохранения.
4. Вернуться в меню. «Продолжить» должно стать доступно; после перезагрузки оно возвращает в ту же сессию.
5. Нажать «Начать игру» при существующем сохранении. Проверить «Отмена», затем подтвердить новую игру.
6. Проверить звук в верхней панели, полный экран, узкое окно, Escape в лобби и в настройках лобби.
