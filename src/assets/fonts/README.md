# Interface fonts

Bundled locally so the game does not request fonts from external services at runtime.

- Oswald Variable (200–700): https://github.com/google/fonts/tree/main/ofl/oswald
- Golos Text Variable (400–900): https://github.com/google/fonts/tree/main/ofl/golostext

The original font binaries are unmodified. Both families include Cyrillic. Their SIL Open Font License texts are included as `Oswald-OFL.txt` and `GolosText-OFL.txt`.
