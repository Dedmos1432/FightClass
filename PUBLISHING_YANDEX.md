# Fight Class 0.6.0: проверка сборки в Яндекс Играх

## Локальная версия

```powershell
npm ci
npm run dev -- --port 5185
```

Открыть `http://127.0.0.1:5185/`. Обычная версия и GitHub Pages работают самостоятельно. В них SDK не загружается; локальное сохранение остаётся основным.

На телефоне удобнее альбомная ориентация. Слева удерживаются стрелки движения; справа — блок, уклонение и Q/W/E. В комнатах вместо ударов появляются E («Действие») и «Назад». Для жима есть отдельные «Жать» и «Завершить». В обучении подсказки автоматически объясняют сенсорные кнопки. Окна и длинные карточки прокручиваются пальцем.

## Архив

```powershell
npm run package:yandex
```

Команда собирает `dist-yandex/` и создаёт `artifacts/fight-class-yandex-0.6.0.zip`. Python используется только для упаковки; для пересборки оптимизированных изображений дополнительно нужен Pillow (`python tools/optimize_backgrounds.py`). Сам браузер Python не использует. Генератор проверяет CRC архива, наличие `index.html` в корне, имена без пробелов/кириллицы, размер распакованных файлов до 100 MB и загрузчик `/sdk.js`. Состав и SHA-256 находятся в `artifacts/yandex-build.json`.

Версия для архива использует относительный base `./` и подключает SDK динамически с `/sdk.js`, как требует [официальная инструкция](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about). Сам SDK в архив не включён. Параметр `/FightClass/` предназначен только для GitHub Pages (`npm run build:pages`).

## Черновик платформы

1. Открыть свою игру в [Консоли Яндекс Игр](https://games.yandex.ru/console/), вкладку «Черновик».
2. Загрузить ZIP в поле «Архив» и указать версию `0.6.0`.
3. Выбрать русский язык, desktop и мобильные устройства; для боёв рекомендуется альбомная ориентация. Название — Fight Class. Не заявлять проверку устройств и браузеров, которые ещё не проверены вручную.
4. Открыть игру в режиме черновика с debug-панелью. При первом интерактивном меню Game Ready должен стать зелёным. Смена меню/игры/паузы должна переключать индикатор Gameplay.
5. Пройти новую игру: боевые уроки → качалка и настоящий жим → доска карьеры → запуск бесконечной серии. Проверить обычный карьерный матч до 2 побед и босса до 3.
6. Во время игры вызвать паузу платформы/стартовую рекламу: бой, выносливость, таймер, анимации и звук должны остановиться. После закрытия продолжится тот же момент; ранее открытая ручная пауза остаётся открытой.
7. Сделать тренировку, выйти в лобби и подождать не менее 10 секунд для отправки облачного снимка. Закрыть и открыть черновик; проверить продолжение. Затем проверить тот же игровой аккаунт на другом устройстве.
8. Проверить Android и iPhone: сочетание движения с ударом/блоком, отмену касания, уклонение, жим, прокрутку карточек, поворот экрана, сворачивание/возврат и выключение звука. В репозитории автоматические сенсорные проверки выполнялись в Chrome; проверка физических телефонов и Safari не подменяется эмуляцией.

[Архив и технические параметры черновика](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft), [debug-панель](https://yandex.ru/dev/games/doc/ru/console/debug-panel), [события паузы](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events).

## Сохранения и SDK

- `LoadingAPI.ready()` отправляется один раз, после создания интерактивного интерфейса. `GameplayAPI.start/stop` соответствуют игре, меню, диалогам, результату, уходу во вкладку и паузе платформы.
- Облачный прогресс использует `getPlayer()` и `getData/setData` без запроса авторизации. В облако отправляется полный проверенный снимок с карьерой, тренировками, стилем, обучением и сохранёнными боями. Настройки звука остаются локальными для устройства.
- При запуске выбирается более новый валидный снимок по `updatedAt`; части разных сохранений не смешиваются. Более поздняя локальная запись, сделанная во время загрузки облака, защищена от перезаписи. Старая/повреждённая запись не заменяет валидную.
- Записи объединяются и отправляются не чаще одного раза в 10 секунд. Ошибка облака сохраняет локальную копию и допускает повтор. Это не синхронизация одновременной игры на двух устройствах: перед сменой устройства следует дать снимку отправиться. Закрытие вкладки не гарантирует завершение сетевого запроса, поэтому локальная запись всегда сохраняется сразу.
- При недоступности SDK или облака игра запускается с локальными сохранениями. Проверка платформы должна подтвердить доступность настоящего SDK; локальный fallback не считается прохождением модерации.

Справка: [готовность и геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events), [облачные данные](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player).

## Текст «Как играть» для черновика

Двигайся влево и вправо на A/D или стрелках. Q, W, E — три удара; нажимай следующий удар в конце восстановления для комбинации. Пробел — удерживать блок, Shift — уклонение, Escape — пауза. Береги выносливость: без неё не получится атаковать или уклониться. На телефоне используй кнопки на экране.

В лобби подходи к объектам и нажимай E: левая дверь ведёт в качалку, правая — в зал бесконечных боёв, доска между ними — в карьеру. Жим повышает HP и выносливость, завершённые серии бесконечного режима — общий урон. Повторные нажатия E или «Жать» выполняют жим. В бесконечной серии HP между соперниками не восстанавливается; награда сохраняется после поражения. В карьере проходи соперников по порядку: обычные матчи до двух побед в раундах, боссы — до трёх. Стили меняют анимации атак; их боевые параметры одинаковы для соответствующих слотов. Прогресс сохраняется автоматически.

Архив подготовлен для публикационного тестирования. В Консоль он автоматически не загружался, заявка на модерацию не отправлялась. Иконку, обложку, описание, скриншоты и возрастной рейтинг нужно проверить и заполнить в своей карточке игры перед отправкой.
